# テンプレートから独立したゴーストを作る

## 使うとき

作者が「自分のゴーストを作りたい」「テンプレートから独立させたい」「サンプルゴーストから独立させたい」「ゴーストの名前を変えたい」と言ったとき。

**作者にはっきり頼まれたときだけ行う。自分から始めない。** 名前、作者情報、台詞など、ゴーストの根幹をまとめて書き換える。

何を変えるかの一覧は、`references/standalone.md` と、テンプレート（サンプル）固有の項目が書かれた今の `GHOST.md` にある。この文書には、作者に聞くことと進め方を書く。

## 手順

1. 次のことを作者に聞く。推測で決めない。
   - ゴーストの名前（descript.txt の `name`、install.txt の `name`）
   - `\0` 側と `\1` 側のキャラクター名と、それぞれの一人称・口調・性格
   - 作者名（`craftman` は半角英数、`craftmanw` は表示名）と作者の URL
   - インストール先のフォルダ名（install.txt の `directory`。半角英数で、他のゴーストと重ならないもの）
   - ネットワーク更新をするか。するなら更新ファイルを置く URL
   - シェルをどうするか（`GHOST.md` にある今のシェルのライセンスを伝える。改変した画像の配布が許されていないことがある）
2. 変更するファイルと内容を一覧にして見せ、了承を得てから編集する。
3. `GHOST.md` を新しいゴーストの内容に書き直す（名前、キャラクター、使えるサーフェス、ライセンス）。テンプレート固有の項目の節は、済んだものを消す。辞書の構成やイベントの対応表のうち、変えていない部分は残してよい。
4. 編集が終わったら `scripts/check.ps1`（里々は `-Run` 付き）を通す。華和梨は `scripts/check-dic.ps1 -Event OnBoot` で、起動のトークの実行時のエラーも確かめる。
5. テンプレートのキャラクターに固有の台詞（自己紹介、ランダムトーク、マウス反応など）をどうするか相談する。書き換える場合は、辞書ファイルごとに少しずつ進め、そのつど確認してもらう。台詞を消したり、辞書ファイルを消したりしたときは、その文や関数を呼んでいる側（里々では `＞` でジャンプしたり `＿` の選択肢で呼んだりしている文、YAYA では `EVAL` や文字列で組み立てた名前で呼んでいる関数、華和梨では `${event.${...}}` のように名前を組み立てて呼んでいるエントリ。`scripts/lint.ps1` の K-W2001 も手がかりになる）が残っていないかも確かめる。
