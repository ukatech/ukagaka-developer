# 里々辞書の書き方の要点

里々のゴーストの辞書（`ghost/master/dic*.txt`）を書くときの要点。仕様書は satori-docs（https://ukatech.shillest.net/satori-docs/ 。リポジトリ: https://github.com/ukatech/satori-docs ）。ここに書いた要点は、そこで確かめたもの。構文は推測で書かず、satori-docs で確かめる（ukagaka-doc MCP なら `source` に `satori_docs`。`SKILL.md` の「仕様を調べる」）。ゴースト固有の決まり（どの辞書ファイルに何を書くか、キャラクター、口調）は `GHOST.md` にある。

satori-docs の構成: `grammar/`（文法）、`shiori/`（イベントと動作、`debug.md` に ShioriEcho）、`functions/`（`（）` の内蔵関数）、`system/`（システム変数と組み込み名）、`ssu/`（ssu の関数。正規表現は `ssu/regex.md`）、`other/`（`error-messages.md`、里々 2 の紹介 `satori2-launch.md`、ACP 版との違い `unicode-changes.md`）。

## 里々のバージョン（里々 2 が前提）

このスキルは、里々 2（Unicode 版。`satori.dll` のバージョン記号 `McXYY-Z` の X が 2）のゴーストを前提に書いている。版は `scripts/doctor.ps1` の `SATORI build`（`phase Mc206-2 (Unicode build)` のように出る。ACP 版なら `(ACP build)`）や、`scripts/shiori.ps1 -Event version` で分かる。

- **サポート対象は里々 2 だけ。** 更新されているのは Mc2XX だけで、ACP 版（`Mc1XX`）は致命的な問題のバックポートが検討される程度。
- **里々 1（ACP 版）のゴーストでは、作者に里々 2 への更新を強く推奨する**（頼まれるまで自分では更新しない。手順は `references/satori/update.md`）。`satori.dll` を置き換えるだけ（drop-in）で、辞書もセーブデータもそのまま読め（Shift_JIS のままでよい）、互換性の報告も些細なものしかない。ただし一度里々 2 で起動すると、セーブデータが UTF-8 になって元の版に戻せないので、更新の前にバックアップを取ってもらう。
- 作者が見送ったら、そのゴーストでは里々 2 の機能（`regex_` 関数、選択肢の引数、`＊OnSatoriTimer`、変数の一括操作と `split_to`、UTF-8 の辞書など）を使わない。ssu も、Mc201-5 より前は `saori/ssu.dll` を `＠SAORI` に登録して使う。
- 里々 1 の挙動に頼った辞書は、里々 2 で結果が変わる。式の `^` はビット XOR からべき乗に、`=~` と `!~` は常に 0 から部分文字列の判定に、計算は 32 ビットから 64 ビットに、`（バイト値、n）` は Unicode のコードポイントの 1 文字を返すようになった。ほかの違いは `other/satori2-launch.md` と `other/unicode-changes.md`。
- 里々 2 の中でも、機能ごとに入った版が違う。版が書いてある機能は、ゴーストの `satori.dll` がその版以降か確かめてから使う。

## 辞書の書き方

- 辞書は、行頭が `＊`（全角）か `＠`（全角）の行で区切られたユニットの並び。最初のユニットより前の行は、コメントとして無視される。辞書のファイルは、`ghost/master/` の直下にある `dic` で始まり `.txt` で終わるものがすべて読まれる（ほかの名前のファイルは読まれない）。`another/` のようなサブフォルダは、`＄辞書フォルダ` で指定したときだけ。
- **文（トーク）**: `＊名前` の次の行から、次の `＊` か `＠` の行の手前までが本文。同じ名前の `＊` を複数書くと、呼ばれるたびにその中から 1 つが選ばれる。全体を選ぶ条件は、名前の後にタブで区切って式を書く（`＊OnBoot<タブ>（好感度）>=50`。式が真のときだけ候補になる）。
- **ランダムトーク**は、名前のない `＊`。`＄喋り間隔`（秒）ごとに、名前のない文の中から 1 つが選ばれる。
- **単語群**: `＠名前` の次の行から、**1 行が 1 つの単語**。本文の中で `（名前）` と書くと、その中から 1 つが選ばれて展開される。単語の中にも `（）` を書ける。同じ名前の `＠` を複数書くと、1 つにまとまる。
- **`（）` の展開**: 本文の全角の `（` `）` は、里々が展開する。展開の順序は、関数（`（calc、1+2）`）→ 単語群 → 文 → 変数 → 数字（サーフェスの切り替え）→ 組み込み名（`（現在時）` など）。入れ子にでき、内側から展開される。文字として出したいときは `φ（` `φ）`（`φ` の直後の 1 文字は、記法として解釈されない）。閉じていない `（` があると、読み込みでエラーになる。
- 関数の引数は、`、` `,` などで区切る（最初に見つかった 1 種類だけが区切りになる）。`（）` の中の `（）` は、先に展開されてから引数に分けられる。
- **`：`（全角のコロン）は話者の交代**。トークは最初、相方側（`\1`）が話す状態で始まり、最初の `：` で本体側（`\0`）になり、以降は交互に入れ替わる。台詞の中に文字としての `：` を書くときは `φ：`。
- **変数**: 行頭が `＄` の行で代入する。
  - `＄名前<タブ>値`: 値の `（）` を展開して、そのまま入れる。
  - `＄名前＝式`: 式を計算して入れる。結果が整数のときは**全角の数字**になる（`＄好感度＝（好感度）+1`）。式の中の計算のカッコは、半角の `( )`（全角の `（` `）` は展開に使われる）。
  - タブも `＝` も無い行はエラーになり、そこでトークが打ち切られる。読むときは `（変数名）`。存在しない変数は `（変数名）` のまま残る（式の中では `０`）。
  - `＄` で代入した変数は、ゴーストの終了時に `satori_savedata.txt` へ自動で保存され、次の起動で戻る。
- **ジャンプと呼び出し**: 行頭の `＞名前` は、その名前の文へジャンプする（元の文には戻らない。`＞名前<タブ>条件式` は、式が真のときだけ）。`≫`（コミュニケート用の文を探すジャンプ）、`≧`（タグ検索）もある。`（名前）` は呼び出しで、結果が元の文に埋め込まれ、続きも実行される。引数付きは `（call、名前、引数）`（呼ばれた側では `（A0）`）。
- **選択肢**: 行頭が `＿` の行が `\q[ラベル,ID]` になる（`＿ラベル<タブ>ID` でラベルと ID を分けられる）。選ばれると、`＊OnChoiceSelect` があればそれが、なければ ID と同じ名前の文が実行される。`＿ラベル<タブ>ID<タブ>引数…` と書くと、選ばれた文が引数を `（Ａ０）` `（Ａ１）`… で受け取れる（Mc201-11 以降）。
- **イベント**: SHIORI のイベントには、イベント名と同じ名前の文で反応する（`＊OnBoot` など）。Reference は `（Ｒ０）` `（Ｒ１）`…（半角の `R0` でも書ける）。`OnBoot` → `起動`、`OnClose` → `終了`、`OnFirstBoot` → `初回`、`OnGhostChanged` → `他のゴーストから変更` のような、古い里々の名前でも書け、上の名前の文が無ければ下を探す。マウス反応は `＊0Headなでられ` のように、スコープ番号と当たり判定名で書く。どの辞書ファイルに書くかは `GHOST.md` の「イベントと辞書ファイルの対応」を見る。**同じイベント名の文を別の辞書に足すと、候補が増えてランダムに選ばれる。**
- **里々独自の文**: `＊初期化`（`satori_conf.txt`。最初に 1 度）、`＊OnSatoriLoad`（辞書の読み込み後）、`＊OnSatoriBoot`、`＊OnSatoriClose`、`＊OnSatoriUnload` など。
- **`satori_conf.txt` は、`＊初期化` と `＠SAORI` の 2 つだけが有効**（ほかの文や単語群を書いても、読み込みのあとで捨てられる）。`＊初期化` にシステム変数（`＄喋り間隔` など）の初期値を書く。セーブデータより先に読まれるので、保存済みの変数は上書きしない。`＠SAORI` に、`呼び出し名,相対パス` の形で SAORI を登録する。
- **ssu の関数**（`calc` `if` `substr` `split` `replace` `sprintf` など）は、里々 2 の `satori.dll` に内蔵されていて（Mc201-5 以降）、`（calc、1+2）` のように使える。`＠SAORI` への登録も `ssu.dll` も要らない。結果は半角の数字になる。里々の内蔵関数（`set` `call` `loop` `when` `times` `while` `for` など）もある。関数の一覧と引数は satori-docs の `ssu/`（ssu）と `functions/`（内蔵関数）で確かめる。
- **`＃`（全角）から行末まではコメント**。半角の `#` は普通の文字。文字として出すときは `φ＃`。
- **前処理**: 行末の `φ` は次の行と連結する。`（` から `）` までの間の改行は、連結して 1 行として扱われる（続く行の行頭のタブは無視される）。`replace.txt` は辞書を読み込むときの置換、`replace_after.txt` は応答を返す直前の置換（どちらも `置換前<タブ>置換後`）。
- **自動で入るもの**: 各行の終わりに `\n`（`＄自動改行挿入`）と、`。` `、` の後・行末・話者の交代の前などに待ち（`\_w[ミリ秒]`。`＄自動挿入ウェイトの倍率`）。話者を交代したときは、`＄スコープ切り換え時` の文字列（既定は `\n[half]`）が入る。
- **サーフェスの切り替え**は、`（数字）`（`（0）` `（10）` `（-1）`）。いまの話者のサーフェスが `\s[数字]` になる。`\s[..]` を直接書いた場合は、キャラクターごとのサーフェス加算値が足されない。
- **さくらスクリプト**（`\s[0]` `\w5` `\![...]` `\_q` など）は、そのまま書ける。`\\` と `%%` は、エスケープとして出力される。`%username` のような `%` の置換タグも、そのまま出力されてベースウェアが展開する。
- 同じ名前の重複を避ける設定は、`＄文「名前」の重複回避＝方法、期間` などの形で書く。`＊初期化` に書いても効かないので、`＊OnSatoriLoad` に書く。既定では、文は 1 周するまで同じものが選ばれない。
- 辞書を書き換えたら、ゴーストの起動中に `＄辞書リロード＝実行` で再読み込みできる（ゴーストごとのキー割り当ては `GHOST.md`）。デバッグは satori-docs の `shiori/debug.md`（ShioriEcho）、エラーは `other/error-messages.md`。

## 正規表現（里々 2。Mc203-1 以降）

ssu の `regex_` で始まる関数が、正規表現（uka_regexp。PCRE2 に近い構文）で文字列を調べる。仕様は satori-docs の `ssu/regex.md`（共通の書き方）と、`ssu/regex_match.md` などの関数ごとのページ。ほかの ssu の関数と同じく `satori.dll` に内蔵されていて、`＠SAORI` への登録は要らない。

- **関数**: `regex_match`（一部が合えば 1、なければ 0。全体が合うかを調べるときは `^` と `$` で挟む）、`regex_find`（最初に合った位置。なければ -1）、`regex_findall`（合った個数）、`regex_count`（個数だけ）、`regex_replace` / `regex_replace_first`（すべて / 最初の 1 か所を置換）、`regex_erase` / `regex_erase_first`（取り除く）、`regex_split`（区切って分ける）、`regex_escape`（特殊文字に `\` を付ける）。
- **書式**: `（regex_match、対象、パターン、オプション）`。オプションは省略でき、`i`（大文字小文字を区別しない）、`s`（`.` が改行にも合う）、`m`（`^` `$` が行頭・行末に合う）、`x`（空白とコメントを無視する）を並べる。
- **結果の取り出し**: `regex_match` と `regex_find` は、`（S0）`（合った部分全体）と `（S1）`…（括弧のグループ）に入れる。`regex_findall` と `regex_split` は、結果を `（S0）`… に入れる（`regex_split` の個数は `（Sの数）`）。置換後の文字列では `$1`、`${名前}`、`$&`、`$$` が使える。戻り値（1 や 0 や個数）は、そのまま台詞に出る。出したくないときは、`＄m<タブ>（regex_match、…）` で変数に入れる（`＝` だと全角の `１` になる）か、`（when、（regex_match、…）、あり、なし）` のように条件に使う。

  ```
  （regex_replace、日付2024-05-06、(\d+)-(\d+)-(\d+)、$3/$2/$1）     → 日付06/05/2024
  （regex_match、abc123def、(\d+)）（S0）/（S1）                      → 1123/123（先頭の 1 は戻り値）
  ```

- **里々の中で書くときの注意**:
  - `\` と半角の `( )` は、そのままパターンに書ける。全角の `（` `）` は里々の記法として先に展開されるので、文字として使うときは `φ（` `φ）` と書く。
  - 引数は `、` で区切る。区切りは最初に見つかった 1 種類だけなので、`、` で区切っていれば、パターンの中の `{1,2}` の `,` は区切りにならない。
  - **対象が数字で始まり、式として計算できる形だと、里々が先に計算してしまう**（`（regex_replace、1+2、\+、plus）` は、置換の前に `1+2` が `3` になる。`2026_10` のような、式にならない文字列はそのまま渡る。`＄SAORI引数の計算`）。そういう文字列は、先頭に文字を付けて避ける。
- **日本語**: `\w` `\d` `\s` `\b` は ASCII だけが対象で、`（regex_match、日本語、^\w+$）` は 0。日本語の範囲は `[ぁ-ん]` `[ァ-ヶ]` `[一-龠]` のように書く。ひらがな、漢字、絵文字は、`.` や `[^a]` で 1 文字として扱われる。
- **パターンを組み立てる**（Mc205-3 以降）: パターンの中の `(?&名前)`（`(?P>名前)` `\g<名前>` も）は、`（名前）` を展開した結果をパターンとして取り込む。名前は `（名前）` と同じ順（SAORI・内蔵関数、単語群、文、変数、内蔵変数）で探される。
  - 部品にする変数は、**タブ区切り**で代入する（`＄year<タブ>\d{4}`）。`＄year＝\d{4}` のように `＝` で代入すると値が式として計算され、パターンによってはエラーになる（`＄two＝(?&year)_(?&mon)` は `式が計算不能です`）。
  - 単語群から取り込むと、そのたびにランダムに選ばれる。名前がどこにも無いと、`正規表現の書式が正しくありません（undefined subroutine '名前'）。` というエラーになる。
- **外部から来た文字列**（ユーザーが入力した語や `（Ｒ０）` など）をパターンの一部にするときは、`regex_escape` を通す。
- **エラー**: 書式の誤りは `正規表現の書式が正しくありません（…）。`、バックトラックが多すぎるときは `正規表現の照合に時間がかかりすぎたので打ち切りました。`（Mc205-3 以降。それより前は報告されない）が、台詞に出る。見方は `references/satori/check.md`。

## トーク（さくらスクリプト）の書き方

間の取り方、改行の入れ方、話し手の交代などの決まりと例は、`GHOST.md` の「トークの書き方」にある。どのゴーストにも共通すること:

- 里々では、`：` で話者を切り替える。`：` を書かずに行から始めると、相方側（`\1`）が話す。`：` を書くのは、話者を切り替えたいときだけ。
- 表情は `（数字）` で切り替える。サーフェス番号は `GHOST.md` の表にあるものだけを使う。
- 改行、待ちは、里々が自動で入れる（1 行の終わりの `\n`、`。` `、` の後の待ち）。手で `\w` などを書くのは、特別な間が欲しいときだけ（このゴーストでの決まりは `GHOST.md`）。

## 里々でやりがちな失敗

共通の失敗（長すぎる台詞、存在しないサーフェス番号、口調の混在、`\\`、危険なタグなど）は `references/ai-guidelines.md`。里々では次にも気をつける。

- 自動改行があるのに、行末に `\n` を書く。逆に、1 行に長い台詞をつなげて、吹き出しの幅を超える。全角 20〜25 字くらいを目安に、行を改める。
- 自動ウェイトがあるのに、`\w` を大量に書く。`replace_after.txt` が `…` の直後に `\w3` を足すゴーストでは、手で書かない。
- 台詞の中の `（` `）` `：` `＃` を、そのまま書く。`（笑）` は名前の展開として扱われて `not found` になり（数字だけなら `（5）` はサーフェスの切り替え）、`：` は話者が変わり、`＃` からはコメントになる。文字として出したいときは `φ` を前に付ける。
- 本文の行を、`＊` `＠`（新しいユニットになる）、`＄` `＞` `≫` `≧` `＿`（代入、ジャンプ、選択肢になる）で始める。
- `＄名前＝式` の右辺で、全角の `（` `）` を計算のカッコに使う。半角の `( )` で書く。`＄名前<タブ>値` に式を書いても、計算されない。`==` は文字列としての比較（`01==1` は偽）。
- 文字通りのタブを書くべきところにスペースを書く（`＊名前<タブ>条件` や `＄名前<タブ>値`）。エディタが自動でタブをスペースに変えないか確かめる。
- 変数と、同じ名前の文や単語群を作る。`（名前）` は単語群、文、変数の順に探すので、意図しないものが展開される。
- `satori_conf.txt` に、`＊初期化` と `＠SAORI` 以外を書く（読み捨てられる）。
- 里々 1（ACP 版）のゴーストで、作者に更新を強く推奨しないまま里々 2 の機能を使う。
- 正規表現（「正規表現」の項）: `regex_match` を全体一致のつもりで使う、`\w` `\d` で日本語を判定する、`1+2` のような式に見える対象を渡す、パターンの変数を `＝` で代入する、パターンの全角の `（` `）` を `φ` なしで書く。
